# Agent rules
1. Preserve the simple standalone HTML/CSS/JavaScript implementation unless a change is required to fix a reproducible bug.
2. Do not invent successful tests, deployments, features, hospital integrations, or real-time cross-device sync.
3. Use fictional sample patient data only. Never request Aadhaar, ABHA, real patient identifiers, or real medical records.
4. Emergency guidance must always state that the user should go to Emergency/Casualty or tell staff now; never require a token or automatically classify emergencies.
5. A visible control must have a working action. Avoid new dependencies, paid services, and unnecessary redesigns.
6. Test the actual flow after changing code and describe any unverified behavior honestly.
